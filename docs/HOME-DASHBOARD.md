# 홈 화면 구성

- **오늘의 출퇴근** 박스 왼쪽에는 출근·퇴근 시각과 출퇴근 등록 버튼을 표시합니다. 오른쪽에는 **오늘의 업무를 한눈에.** 제목 아래 보라색 **내 결재 진행 중**, 파란색 **승인 대기** 카드가 위아래로 표시됩니다. 일반 직원의 두 번째 카드는 **내 승인 완료**입니다. 카드를 누르면 해당 결재함이 열립니다.
- 별도 상단 배너를 제거했습니다. 출퇴근과 최근 공지사항 박스는 PC에서 기존 150px의 1.5배인 **225px** 높이를 사용하고, 제목·시각·결재 숫자의 크기와 여백을 조정했습니다.
- 사용자 선택에 따라 달력은 고정 1.5배 확대 대신 **한 화면에 맞춤**을 우선합니다. PC 홈에서는 창 높이와 월별 4·5·6주 구성에 맞춰 날짜 칸 높이가 자동 조절됩니다. 상단 메뉴와 안내 영역도 작은 높이로 표시합니다. 긴 좌측 메뉴는 독립적으로 스크롤할 수 있습니다.
- 칸에 표시할 공간이 부족한 일정은 **+N 더보기**에 합칩니다. 누르면 해당 날짜의 모든 일정과 승인 휴가를 볼 수 있습니다. 일정 제목을 누르면 기존 권한에 따라 상세·수정 창이 열리고, **+ 일정 등록**을 누르면 선택 날짜로 작성합니다. Esc 또는 닫기로 돌아갑니다.
- 회사·개인·초대 일정과 이사 승인 휴가의 기존 조회 권한을 유지합니다. 월 이동, 일정 등록·수정·삭제와 일정관리 연동도 유지됩니다.
- 화면 맞춤은 브라우저 내부 너비가 1001px 이상, 높이가 680px 이상인 PC 화면에 적용됩니다. 모바일이나 이보다 작은 창에서는 읽기 쉬운 높이와 세로 스크롤을 사용하고, 일정 이름을 모두 표시합니다. 일정관리·프로젝트 등 다른 메뉴의 화면 크기는 변경하지 않습니다.

## 적용

서버 종료 → 기존 `data` 전체 백업 → 새 프로젝트 폴더에 `data` 전체 복사 → `START-LOCAL.cmd` 실행 → Edge **Ctrl+F5**.

`node_modules`는 복사하지 않아도 됩니다. 실행 스크립트가 필요한 의존성을 설치합니다. 기존 데이터 구조를 변경하지 않습니다.

## 검증

- `npm test`: 기존 기능과 권한 검증.
- `scripts/home-dashboard-smoke.mjs`: 실제 Chromium에서 여러 PC 해상도와 4·5·6주 달력의 화면 맞춤, 날짜·더보기 버튼의 잘림, 모든 일정 확인, 키보드와 포커스 복귀, 수정·등록 연결, 모바일 표시를 확인합니다.
- 기존 홈 캘린더·공지사항·비밀번호·업무 화면 브라우저 검사도 실행합니다. 모두 별도 임시 데이터로 검증합니다.
