# 메일 작성·읽기 화면과 이미지 서명

전자메일의 메일쓰기와 받은메일·보낸메일 열람은 메일함 오른쪽 영역에서 진행합니다. 작성 화면의 목록으로/닫기, 읽기 화면의 목록으로 돌아갈 수 있습니다. 읽기 화면에서는 회신, 본문 전달, 첨부파일 다운로드와 메일함 이동을 지원합니다. 본문 전달은 원문 텍스트를 복사하며 원본 첨부파일은 자동 재첨부하지 않습니다.

계정 설정에서 서명 텍스트와 PNG/JPG 이미지 한 장을 저장할 수 있습니다. 이미지는 최대 1MB, 가로·세로 각각 4000px 이하입니다. 제거 버튼으로 이미지를 지울 수 있습니다. 발신 계정을 변경하면 해당 계정의 서명이 작성 화면에 표시됩니다. 발송 시 일반 텍스트 본문과 함께 이스케이프한 HTML 및 CID 이미지가 생성됩니다. 보낸메일에 저장되는 이미지도 해당 발송 시점의 이미지입니다.

받은메일의 본문은 기존과 같이 안전한 텍스트로 표시하며 외부 HTML과 원격 이미지는 자동 실행·로드하지 않습니다. 새로 수신한 PNG/JPG 인라인 이미지(1MB 이하)는 본문 아래에 표시됩니다. 다운로드와 서명 이미지 조회는 해당 메일 계정 소유자만 가능합니다.

근태관리 하단 기록은 페이지당 최대 5개이며 이전/다음으로 나머지를 조회합니다. 날짜, 출퇴근 시각과 관리자 수정·삭제 기능은 유지하며 행·버튼 높이를 줄였습니다.

업데이트 전 data 폴더를 백업하고 서버를 재시작하세요. 서명 이미지와 인라인 이미지 표시용 DB 열은 시작 시 추가됩니다. 메일 연결 정보·기존 메일은 보존합니다.
