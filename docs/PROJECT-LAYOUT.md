# 프로젝트 화면 정리

## 프로젝트 워크보드

프로젝트 카드의 글자 크기는 그대로 두고 높이와 여백을 약 2/3 크기로 줄였습니다. 프로젝트명 옆에 계획·진행·보류·완료 상태를 표시합니다. 카드에서는 담당자 표시를 제외하며, 고객사·기간·진척률·완료 공정 수를 표시합니다. 긴 이름은 말줄임표로 표시하고 마우스를 올리거나 프로젝트를 선택하면 전체 내용을 확인할 수 있습니다.

## 선택한 프로젝트

다음 순서로 서로 분리된 박스를 표시합니다.

1. **프로젝트 정보**: 이름, 고객사, 기간, 등록자·담당자·참여자, 설명, 상태 선택·저장, 프로젝트 수정, 공정 등록. 기존 프로젝트 변경 기록은 접어서 확인합니다.
2. **공정 수행 내역**: 선택한 월의 공정을 두 줄로 표시합니다. 첫 줄은 공정명과 빨간색 진척률, 둘째 줄은 기간·담당자·참여자·완료 일수입니다. 카드 높이는 기존의 약 1/3입니다. 긴 요약은 마우스를 올리거나 공정명을 눌러 상세에서 확인합니다.
3. **공정 캘린더**: 조회 월, 전체 진척률, 진행 막대와 날짜별 공정·연결 일정입니다. 날짜별 완료 체크와 일정 변경에 따른 진척률 재계산은 동일하게 동작합니다.

## 일자별 수행 내역

공정명을 누르면 첫 줄에 **수행일자 · 수행 내역 · 작성자**, 둘째 줄에 **작성한 수행 내용**을 표시합니다. 긴 내용과 여러 줄로 입력한 내용은 잘리지 않고 줄바꿈됩니다. 작성자에 마우스를 올리면 기록 시각을 확인할 수 있습니다.

공정 등록·정보 수정·완료 체크 같은 자동 기록은 수행 내용 목록에서 제외합니다. 이전 버전에서 직접 작성한 수행 내용은 `기존 수행 내역` 대신 `수행 내역`으로 표시하며, 별도 수행일자가 없으면 기록일의 한국 날짜를 사용합니다. 일정 변경 전후와 사유·작성자는 아래 **일정 변경 이력**을 펼쳐 확인할 수 있습니다. 화면 정리 과정에서 저장된 기록을 삭제하지 않습니다.

## 업데이트

서버를 종료하고 기존 `data` 전체를 백업한 뒤 새 프로젝트 폴더에 복사하세요. `START-LOCAL.cmd` 실행 후 Edge에서 **Ctrl+F5**를 누르세요. `node_modules`는 복사하지 않아도 됩니다.

검증: `npm test`, `scripts/workspace-smoke.mjs`, `scripts/project-members-smoke.mjs` 및 임시 데이터로 진행한 PC·모바일 브라우저 확인. 글자 크기 유지, 카드 높이, 영역 순서, 실제 수행 내용과 이전 기록 표시, 일정 변경 사유, 상태 저장, 일자별 완료 체크, 수행 내용 추가와 조회 월 변경을 확인합니다.
