# 홈 상단과 공지사항 게시판

## 홈

- **오늘의 업무를 한눈에** 배너는 PC에서 약 절반 높이로 줄였습니다. 배너의 신규기안·결재함 버튼을 제거했습니다.
- 보라색 **내 결재 진행 중**, 파란색 **승인 대기** 카드를 배너 안으로 옮겼습니다. 84px 정사각형 두 개를 중앙선 왼쪽에 나란히 배치합니다. 결재 권한이 없는 직원의 두 번째 카드는 기존처럼 **내 승인 완료**를 표시합니다.
- 별도의 공지사항 숫자 카드는 제거했습니다. 최근 공지사항 목록은 계속 표시하며, 제목을 누르면 본문을 열 수 있습니다.
- 작은 화면에서는 배너 설명과 두 카드가 줄바꿈됩니다. 달력의 날짜 칸 높이는 유지하며, 전체 화면에서 보이는 범위는 창 높이와 브라우저 확대 비율에 따라 달라집니다.

## 공지사항

검색창과 글쓰기 버튼 아래에 **상태 / 제목 / 작성자 / 작성일 / 답변** 표를 표시합니다. 기존 공지사항 화면의 로고 색상과 패널·버튼 디자인을 사용합니다.

- 제목 또는 작성자로 검색합니다. 게시글은 최신 등록 순으로 한 페이지에 10개씩 표시하며, 이전·다음 버튼으로 이동합니다. 100건보다 오래된 게시글도 검색·조회할 수 있습니다.
- 제목을 누르면 본문·작성자·한국 시간 작성일시와 답변이 열립니다. 줄바꿈을 유지하며 입력 내용은 텍스트로 표시합니다.
- **글쓰기**를 누를 때 작성 창이 열립니다. 공지 작성은 기존과 동일하게 이사·대표이사 결재 역할의 계정만 가능합니다. Admin 권한만으로 작성 권한이 추가되지는 않습니다.
- 로그인한 직원은 공지를 열고 답변을 등록할 수 있습니다. 목록의 답변 수는 실제 저장된 답변 수입니다. 답변 수를 누르면 답변 작성 위치로 이동합니다.
- 기존 공지사항을 보존하고 답변 저장 테이블을 자동 추가합니다. 사용자 삭제 시 해당 사용자의 답변도 삭제되며, 작성자의 공지를 삭제할 때 그 공지의 답변도 함께 삭제됩니다.

## 적용과 검증

서버 종료 → 기존 `data` 전체 백업 → 새 프로젝트 폴더에 `data` 전체 복사 → `START-LOCAL.cmd` 실행 → Edge **Ctrl+F5**.

`npm test`와 `scripts/home-notice-board-smoke.mjs`, 기존 홈 캘린더·UI 브라우저 검증을 사용합니다. 임시 데이터로 공지 권한·검색·페이지 이동·답변 수·사용자 삭제 연동·이전 데이터 유지와 PC·모바일 화면을 확인합니다.
