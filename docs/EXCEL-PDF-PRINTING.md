# 전자결재·업무보고 엑셀 → PDF 출력

## 업데이트 후 출력 방법

1. 서버를 종료하고 기존 `data` 폴더 전체를 백업합니다. 새 프로젝트 폴더에 기존 `data` 폴더 전체를 복사한 뒤 `START-LOCAL.cmd`를 실행합니다.
2. Edge에서 `Ctrl+F5`로 새로고침합니다.
3. 그룹웨어에서 승인된 문서를 열고 **엑셀 다운로드를 다시 실행**합니다. 이전에 다운로드한 엑셀 파일은 자동으로 바뀌지 않습니다.
4. Excel에서 새 파일을 열고 **양식** 시트를 선택합니다.
5. **파일 → 내보내기 → PDF/XPS 만들기** 또는 **파일 → 인쇄 → Microsoft Print to PDF**로 출력합니다.

기본 인쇄 설정은 **A4 / 세로 / 너비 1페이지 / 높이 자동**입니다. 길이가 긴 문서는 여러 페이지로 이어집니다. 인쇄 화면에서 배율을 직접 바꾼 경우 **모든 열을 한 페이지에 맞추기**를 사용하세요. **시트를 한 페이지에 맞추기**를 선택하면 긴 문서 전체가 축소되어 글씨가 작아집니다.

문서 본문만 출력하려면 **활성 시트 인쇄**를 선택합니다. 승인·반려·수정·재상신 이력이 필요하면 별도의 **결재 이력** 시트도 출력할 수 있습니다. 전체 통합 문서를 출력하면 이력 시트까지 포함됩니다.

## 변경 내용

- 웹 화면은 기존 Noto Sans KR을 사용합니다. 다운로드 양식은 Windows 기본 정적 글꼴인 **맑은 고딕(Malgun Gothic)**을 지정합니다. 웹용 가변 글꼴 설치 여부와 PDF 드라이버에 따른 문자 간격 차이를 줄이기 위한 출력 전용 설정입니다.
- 인쇄 영역을 A4 너비에 맞춰 과도한 가로 축소를 줄이고, 글자를 왼쪽 정렬합니다. 양쪽·분산 정렬이나 셀에 맞춘 글꼴 축소를 사용하지 않습니다.
- 한글·영문·숫자·기호 폭을 고려해 줄바꿈합니다. 긴 본문은 작은 행으로 나눠 Excel의 행 높이 제한과 페이지 경계에서 내용이 잘리는 문제를 피합니다. 일일업무일지의 실시사항·예정사항은 좌우로 유지합니다.
- 결재 날짜·시각은 두 줄로 표시하고 서명·도장 이미지를 결재 칸 안에 배치합니다. 현재 상신 회차의 서명만 표시하는 규칙을 유지합니다.
- 지출 금액은 숫자로 유지하며 고액 숫자도 인쇄할 수 있도록 열 너비와 글자 크기를 조정합니다.
- 결재 이력은 별도 시트에 보존합니다. 승인 기록이나 기존 업무 데이터를 변경하지 않습니다.

## 검증

`npm test`로 기존 권한·결재·서명·엑셀 기능과 장문·숫자·한글/영문 인쇄 구조를 검증합니다. 다음 명령은 임시 DB로 실제 다운로드 파일을 생성합니다.

```sh
PRINT_OUTPUT_DIR=/tmp/group-excel-print node scripts/excel-print-smoke.mjs
mkdir -p /tmp/group-excel-print-pdf
soffice --headless --convert-to pdf --outdir /tmp/group-excel-print-pdf /tmp/group-excel-print/*.xlsx
python3 scripts/check-excel-pdf.py /tmp/group-excel-print-pdf
```

변환 검증에는 별도의 LibreOffice와 PyMuPDF가 필요합니다. 서버 실행에는 필요하지 않습니다. 승인된 출장보고서·일일업무일지·지출결의서·휴가신청서 및 빈 양식 16종을 PDF로 변환해 확인합니다. Linux에서는 대체 한글 글꼴을 사용하며, 실제 Windows Excel의 PDF 출력 엔진은 이 환경에서 실행하지 못했습니다.
