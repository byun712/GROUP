# 홈 캘린더와 간결한 목록 구성

## 홈 화면

하단의 **최근 지출결의서·최근 결재 문서** 영역을 제거하고 **스케줄 캘린더**를 배치했습니다. 문서 자체는 전자결재·업무보고 결재함에 그대로 보관됩니다.

- 회사 일정, 내 개인 일정, 내가 초대된 일정, 이사 승인 이후의 휴가를 함께 표시합니다. 일정관리와 동일한 조회 권한을 적용합니다.
- 조회 월을 선택하거나 이전 달·다음 달·이번 달 버튼으로 이동합니다. 기본 월과 오늘 표시는 한국 시간을 기준으로 합니다.
- 날짜를 누르면 일정 등록, 일정 이름을 누르면 상세 확인·수정 화면이 열립니다. 저장·삭제 후 홈 캘린더에 바로 반영합니다.
- **일정관리 열기 →**를 누르면 홈에서 보고 있던 월의 일정관리 화면으로 이동합니다.
- 휴가는 이사 승인 시 표시되고 이후 반려되거나 문서가 삭제되면 제외됩니다. 홈으로 다시 들어올 때 최신 데이터를 조회합니다.

## 일정관리

달력 아래 일정 목록을 **제목 → 날짜·시간·공개 범위·작성자·프로젝트 → 일정 수정 → 연결 프로젝트 열기** 순서로 한 줄에 표시합니다. 행 높이와 버튼 여백을 줄였습니다. 긴 제목·정보는 마우스를 올리거나 일정 상세를 열어 확인할 수 있습니다. 작은 화면에서는 일정 정보를 다음 줄에 배치해 버튼을 사용할 수 있게 합니다.

## 양식 선택

전자결재와 업무보고 모두 **결재함 아래에 양식 선택 영역**을 배치했습니다. 두 화면의 양식 버튼 너비·높이·설명을 같은 구성으로 줄였으며, 기존 신규기안·업무보고 작성 메뉴와 16개 양식은 유지됩니다.

## 적용 및 검증

서버를 종료하고 기존 `data` 폴더 전체를 백업하세요. 새 프로젝트를 별도 폴더에 풀고 기존 `data` 폴더를 통째로 복사한 뒤 `START-LOCAL.cmd`를 실행합니다. Edge에서 **Ctrl+F5**로 새로고침하세요. `node_modules`를 복사할 필요는 없습니다.

자동 테스트: `npm test`. 브라우저 검증: `scripts/home-calendar-smoke.mjs`는 일정 공개 범위, 승인 휴가, 홈에서 등록·수정·삭제, 월·연도 이동, 늦게 도착한 이전 월 응답 처리, 프로젝트 연결, 양식 위치·크기와 모바일 화면을 확인합니다. 임시 DB만 사용합니다.
