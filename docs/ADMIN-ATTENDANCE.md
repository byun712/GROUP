# Admin 공정 삭제와 근태 달력


> 추가 변경: [사용자별 휴가 부여·평일 집계·잔여량 상신 제한](LEAVE-ALLOWANCES.md)을 확인하세요.
## 공정 삭제

프로젝트의 공정을 눌러 수정 창을 연 뒤 **공정 삭제**를 선택합니다. 이 버튼과 서버 삭제 권한은 Admin에게만 있습니다. 이사·대표이사 역할만 있고 Admin이 아니면 삭제할 수 없습니다. 기존의 공정 공동 편집 권한은 그대로입니다.

삭제 확인 후 해당 공정, 날짜별 완료 체크, 모든 수행 내용, 공정 등록/정보 수정/일정 변경 기록을 같은 트랜잭션에서 실제 삭제합니다. 삭제 이력, 휴지통, 별도 보관 문서를 만들지 않습니다. 남은 공정을 기준으로 프로젝트 진척률을 다시 표시합니다. 프로젝트 자체와 연결된 일반 일정은 유지합니다.

조회 후 다른 사용자가 공정을 수정했다면 이전 버전의 삭제 요청은 거절하고 다시 조회하도록 안내합니다. 삭제된 공정 ID를 재사용하지 않습니다. ID 순번만 저장하며 삭제된 공정명이나 내용은 저장하지 않습니다. 이미 만들어 둔 과거 수동 백업에는 그 당시 자료가 남을 수 있습니다.

## 사용자별 근태 달력

- 근태 관리에서 사용자와 조회 월을 선택합니다. 일반 사용자는 본인만 조회하고, Admin은 비활성 계정을 포함한 등록 사용자를 조회할 수 있습니다.
- 출근 시각은 **파란색**, 퇴근 시각은 **빨간색**입니다. 퇴근 기록이 없으면 미등록으로 표시합니다.
- Admin은 달력의 출퇴근 시각 또는 아래 기록 표의 **시간 수정**을 눌러 변경합니다. 입력과 출력은 모두 한국 시간입니다. 출근 날짜는 해당 근태 날짜와 같아야 하며 퇴근 시각은 출근 이후여야 합니다. 익일 퇴근도 허용합니다.
- 퇴근 시각을 비워 저장하면 퇴근 미등록으로 바뀝니다. Admin의 **삭제**는 해당 날짜의 출퇴근 기록을 제거합니다.
- 사용자·월을 선택한 뒤 CSV를 다운로드하면 현재 선택한 사용자·월의 근태를 받습니다. 일반 사용자는 URL을 직접 바꿔도 다른 사용자의 근태나 CSV를 조회할 수 없습니다.
- 실제 출퇴근 등록은 기존처럼 사무실 공인 IP에서만 허용합니다. Admin의 기존 기록 보정 기능은 사외에서도 사용할 수 있습니다.
- 수정·삭제는 최신 버전을 확인하여 동시 수정이나 출퇴근 등록과 충돌하면 저장을 거절합니다. 삭제된 기록 ID는 재사용하지 않습니다.

## 이사 승인 휴가 연동

연차 및 오전/오후 반차는 이사 승인 후 바로 일정관리와 해당 사용자 근태 달력에 표시합니다. 대표이사 최종 결재를 기다리는 동안에도 휴가를 볼 수 있습니다. 전자결재의 대표이사 승인 단계와 서명은 유지합니다. 대표가 반려하거나 대표 결재 전에 작성자/Admin이 문서를 삭제하면 두 달력에서 제외합니다. 이사 승인 전 신청과 회수·반려된 신청은 표시하지 않습니다.

휴가 신청 사유는 달력 API에 반환하지 않습니다. 근태 달력은 해당 사용자의 휴가만 표시하고, 기존 일정관리의 회사 휴가 공유 정책은 유지합니다. 달력에 휴가를 표시해도 출퇴근 기록을 자동 생성하거나 변경하지 않습니다.

## 기존 데이터와 설치

기존 출퇴근 시각과 IP·근태 날짜는 보존합니다. 서버 실행 시 버전 열과 순번 설정만 추가합니다. 기존에 이사 승인을 받고 대표 결재를 기다리는 휴가도 새 버전부터 자동 조회됩니다. 추가 패키지는 없습니다.

기존 서버 종료 → 새 프로젝트를 별도 폴더에 압축 해제 → 기존 `data` 폴더 전체 복사 → `START-LOCAL.cmd` 실행 → Edge Ctrl+F5 순서로 적용합니다. DB만 옮기지 말고 메일 암호화 키 등 기존 파일을 포함한 `data` 전체를 옮기세요. `node_modules`는 새 폴더로 복사하지 않아도 런처에서 필요한 패키지를 설치합니다.

## 검증

Chromium의 `scripts/admin-attendance-smoke.mjs`에서 Admin 사용자 선택·시간 수정·삭제, 파랑/빨강 표시, 휴가 연동, 공정 삭제와 수행 내역 제거, 일반 사용자 버튼 비노출, 선택 사용자 CSV, 모바일 가로 넘침을 확인했습니다. 실제 Windows/Edge 직접 검증과는 구분합니다.
