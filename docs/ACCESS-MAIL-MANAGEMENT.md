# 사용자·회계 권한과 개인 메일함

## 사용자 관리

| 기능 | Admin | 일반 사용자 |
|---|---|---|
| 사용자 생성 | 가능 | 불가 |
| 사용자 정보·로그인 아이디 변경 | 전체 사용자 | 본인만 |
| 결재 역할·Admin 권한·활성 상태 변경 | 가능 | 불가 |
| 사용자 영구 삭제 | 가능 (마지막 활성 Admin 제외) | 불가 |

사용자 관리에서 카드를 눌러 로그인 아이디와 개인정보를 수정합니다. 아이디 변경 시 해당 사용자의 모든 세션이 종료되며 새 아이디/기존 비밀번호로 로그인합니다. 대소문자를 무시한 중복 아이디는 허용하지 않습니다. 직급을 이사·대표이사로 바꾸어도 결재 역할은 자동 변경되지 않습니다. 일반 사용자의 화면에는 역할·Admin 지정 입력란이 없으며 서버도 권한 변경 요청을 거절합니다. 최초 설치를 위한 서버 운영자의 로컬 계정 생성 도구는 유지합니다.

**사용자 영구 삭제**를 누른 뒤 해당 아이디를 입력하고 저장하면 현재 그룹웨어 DB에서 삭제합니다. 계정·비밀번호 해시·세션·프로필·메일 계정/암호화 비밀번호·메일/첨부·개인 메일함/규칙·근태·본인의 결재 문서/승인 기록·일정·등록 프로젝트/공정/수행 내역·등록 고객사/명함·본인 관련 회계 전표와 사용자 관리 이력을 제거합니다. 삭제 시 자동 백업·휴지통·탈퇴자 보관 레코드는 만들지 않습니다.

본인이 등록한 프로젝트/고객사에 속한 하위 자료도 함께 삭제됩니다. 다른 직원이 등록한 프로젝트/일정 자체는 유지하고 삭제된 고객사/프로젝트 연결 및 참여자만 제거합니다. 해당 직원이 기록한 승인/변경 이력도 지워집니다. 마지막 활성 Admin 삭제는 차단하고 메일 송수신 중인 계정은 작업 종료 후 삭제하도록 합니다. 내부 사용자 번호는 재사용하지 않습니다.

삭제 범위는 **현재 그룹웨어 DB**입니다. 과거에 별도로 만든 백업·내보낸 파일·외부 카페24 사서함 원본을 이 버튼으로 삭제하지는 않습니다. SQLite secure_delete 및 WAL 정리를 수행하지만 외부 저장장치·OS 스냅샷의 삭제까지 보장하는 기능은 아닙니다.

## 회계

회계 접근·조회·작성·수정·삭제는 **결재 역할이 이사(manager) 또는 대표이사(ceo)** 인 사용자에게만 허용합니다. Admin만 있고 결재 역할이 직원이면 회계 화면과 API에 접근할 수 없습니다.

회계 전표 카드를 눌러 일자·내용·금액·분개 계정을 수정하거나 삭제합니다. 수정 시 차변/대변 합계와 금액을 검증하고 다른 사람이 먼저 수정한 전표는 재조회하도록 합니다. 직접 작성한 전표는 금액도 수정 가능합니다. 결재 연동 전표 금액은 승인된 지출결의서 금액을 유지해야 하며 일자·내용·분개 계정은 수정할 수 있습니다. 지급 전표를 삭제하면 해당 지출이 다시 지급 대기에 표시됩니다.

지출 승인 전표를 삭제하면 연결 지급 전표도 삭제하며 재시작 시 자동 재생성하지 않습니다. 원래 지출결의서 자체를 취소/삭제하는 작업은 아닙니다. 전표 삭제는 은행 송금 취소가 아닙니다.

## 개인 이메일

모든 사용자는 본인의 외부 이메일 계정을 추가·수정·삭제할 수 있습니다. 다른 사용자의 계정·메일·첨부·메일함·규칙은 접근할 수 없습니다. **계정 설정 → 연결 계정 삭제**는 그룹웨어에 저장된 해당 계정의 메일과 설정을 삭제하며 외부 사서함 원본은 유지합니다.

**이메일 → 메일함·자동 분류**에서 다음 탭을 사용합니다.

- 메일함: 개인 메일함 생성, 이름 변경, 삭제. 삭제 시 메일은 받은메일함으로 이동하고 해당 메일함의 분류 규칙은 삭제합니다.
- 자동 분류: 발신자/제목/수신자/본문에서 검색어 포함 또는 완전 일치 조건, 목적 메일함, 사용 여부, 우선순위를 설정합니다. 영문 대소문자는 구분하지 않습니다. 작은 우선순위부터 처음 일치한 규칙을 적용하며 같은 우선순위는 먼저 만든 규칙이 우선입니다.
- 목록 표시: 기본 20개, 20~100개까지 10개 단위로 설정합니다. 메일 목록의 표시 개수 선택에서도 변경하며 연결 계정별로 저장됩니다.

분류 규칙은 **새 POP3 수신 메일에 자동 적용**됩니다. 기존 메일은 **기존 받은메일에 적용** 버튼으로 다시 분류합니다. 보낸/스팸/휴지통은 재분류하지 않으며 조건에 맞지 않는 받은/개인 메일함의 메일은 받은메일함으로 이동합니다. 메일 읽기 화면에서 개인 메일함을 골라 직접 옮길 수도 있습니다. 전체 받은메일은 기본 받은메일함과 개인 메일함의 수신 메일을 함께 보여줍니다.

이는 그룹웨어 내부 메일함 분류이며 카페24 서버의 폴더를 바꾸는 기능은 아닙니다. POP3 가져오기는 기존과 동일하게 버튼을 눌러 실행합니다.

## 검증

`npm test`: 사용자 생성/자기 정보 변경/권한 탈취 차단/아이디 변경 세션 종료/영구 삭제와 연결 데이터 제거/외래키 무결성, 회계 권한/균형/수정 충돌/삭제 후 재생성 방지, 메일 계정 격리/규칙/실제 가짜 POP3 수신 자동 분류/표시 개수/백업을 검증합니다.

선택 브라우저 검증: `scripts/management-smoke.mjs`. Admin 생성·아이디 변경·영구 삭제, 개인 메일함 이름 변경·규칙·기존 메일 재분류, 20/30개 표시·페이지 이동·설정 저장·모바일 화면, 회계 수정·삭제를 검사합니다. 실제 외부 메일 배달은 기존 안내와 같이 계정 연결 후 확인합니다.
