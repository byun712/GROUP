# 공지·근태·회계·고객·사용자 UI 검증 및 리뷰

## 변경 범위

- 공지: 검색 왼쪽/글쓰기 오른쪽, 인디고 주요 버튼, 넓은 클릭 영역, 제목/메타데이터 위계, 분류 배지, 빈 목록 안내, 작성 입력 간격.
- 근태: 출근/퇴근 좌우 액션, 등록 조건에 따른 상태 안내, 모바일 달력 시간 줄바꿈. 기존 5행 페이지와 관리 기능 유지.
- 회계: 기존 집계값의 요약 카드, 전표 건수 단위, 금액 우측 정렬 및 큰 음수/0원 표시.
- 고객: 회사/기본정보/담당자 순서, 직책과 연락처 그룹, 긴 문자열 줄바꿈.
- 사용자: 데스크톱 표, 모바일 항목명 카드, 독립된 역할·Admin·활성 태그, 수정 및 비밀번호 변경 버튼. 기존 연락처 요약 유지.
- API 권한, 출퇴근 네트워크 제한, 회계 집계, 첨부 저장/다운로드 로직은 변경하지 않음. 공지 컬렉션의 기존 분류만 표시하며 중요도를 새로 만들지 않음.

## 테스트 결과

- `npm test`: 41개 통과.
- `management-smoke.mjs`: 사용자 생성/본인 수정/삭제, 회계 접근·전표 수정/삭제 통과.
- `admin-attendance-smoke.mjs`: 근태 수정/삭제, 승인 휴가, CSV, 권한별 격리 통과.
- `menu-notice-color-smoke.mjs`: 공지 작성/수정/첨부 업로드·다운로드, 메뉴, 프로젝트 그래프·일정 색상 통과.
- `home-notice-board-smoke.mjs`: 홈 배치, 공지 검색/페이지/빈 상태/답변/지속성 통과. 분류 헤더와 새 안내문, 중립 테두리에 맞게 기대값 갱신.
- `design-refinement-smoke.mjs`: 1366×768, 1920×1080, 390×844에서 6개 화면 확인. 긴 제목/회사명/이메일, 하루 일정 12개, 빈 목록, 큰 음수/0원, 근태 5행 페이지, 출퇴근 실제 등록, 고객 이메일 작성 연결, 사용자/이사/Admin 표시 확인.
- `user-password-smoke.mjs`: 본인/Admin 변경, 확인 비밀번호·현재 비밀번호 검증, 세션 만료, 모바일 통과.
- `profile-smoke.mjs`: 본인 수정 범위, 부서/직급 및 일정 참여자 프로필 연동, 모바일 통과. 사용자 표의 행/열 구조에 맞춰 기존 테스트 선택자와 기대값 갱신.
- JavaScript 구문 검사와 `git diff --check` 통과.

모든 브라우저 스크립트는 별도 임시 DATA_DIR과 로컬 서버를 사용하고 종료 시 정리합니다. 큰 음수 회계 값은 임시 브라우저의 렌더링 입력을 바꿔 경계값 표시만 검사하며 실제 집계 기준을 변경하지 않습니다.

## 코드 리뷰 결과

변경된 diff의 이벤트 연결, 권한 분기, DOM 텍스트 생성, 집계 사용, CSS 범위와 모바일 표시를 자체 리뷰했습니다.

- 사용자 표 전환 중 빠진 기존 전화번호/이메일 요약을 이름 아래에 복원.
- 좁은 모바일 근태 셀에서 nowrap이 시간을 자를 수 있어 이름/시간 줄바꿈 허용.
- 실제 중요도 데이터가 없음을 확인하고 기존 '공지'를 '분류'로 명확히 표기.
- 새 검증 스크립트의 서버 길이 제한 초과 데이터, 메일 작성 선택자, 로그아웃 재로드/로그인 초기화 대기를 수정. 이는 테스트 준비 오류이며 업무 권한 로직 변경은 없음.
- 최종 검사에서 미해결 기능/권한 회귀는 발견되지 않음.

## 범위와 제한

Chromium 데스크톱 및 모바일 뷰포트 에뮬레이션으로 확인했습니다. 실제 iOS/Safari/Firefox 검증은 수행하지 않았습니다. 모바일 공지·근태 기록처럼 열이 많은 표는 기존 가로 스크롤을 유지합니다. 외부 메일 실제 발송과 운영 DB 검증은 수행하지 않았습니다.
