# 문서를 복사하여 새로 작성하기

전자결재·업무보고의 문서 상세 화면 **상단 오른쪽 → 복사**를 누르세요. 이사 승인 대기, 대표이사 승인 대기, 승인 완료, 반려, 회수 상태 모두 복사할 수 있습니다. 조회할 수 있는 문서에만 버튼이 표시됩니다.

1. 원문의 양식과 제목·날짜·입력 내용이 채워진 작성 화면이 열립니다.
2. 내용을 수정하세요. 지출결의서는 항목별 금액·거래처·계좌 정보와 첨부파일도 복사됩니다. 파일은 미리보고 추가·제거할 수 있습니다.
3. **결재 상신** 또는 **지출결의서 상신**을 누르면 로그인한 사용자를 작성자로 하여 새 문서번호로 등록됩니다.

복사 버튼만 눌렀을 때에는 새 문서를 저장하지 않습니다. **복사 취소**를 누르면 원문 상세로 돌아갑니다. 새 양식을 선택하거나 작성 중인 브라우저를 닫으면 아직 상신하지 않은 복사 내용은 저장되지 않습니다.

새 문서는 **이사 승인 대기·1차 결재**부터 시작합니다. 원문의 승인·반려 상태, 결재 날짜, 서명·도장, 처리 이력은 이어지지 않습니다. 복사본을 수정하거나 첨부파일을 제거해도 원문과 원본 첨부파일은 바뀌지 않습니다. 지출은 복사 시 회계에 중복 반영하지 않고 새 문서가 최종 승인되었을 때 기존 규칙대로 반영합니다.

휴가 종류와 기간도 그대로 채워집니다. 사용할 날짜를 확인한 뒤 상신하세요. 복사본에도 휴가 잔여 일수, 필수 입력 항목, 첨부 용량 등 기존 신규 상신 검증을 적용합니다. 메뉴에서 제거된 연구개발비 양식은 조회 가능한 기존 문서를 복사할 때에만 재사용할 수 있습니다.

홈 하단은 [스케줄 캘린더](HOME-CALENDAR-LAYOUT.md)로 변경되었습니다. 문서 조회·복사는 전자결재 또는 업무보고 결재함에서 이용하세요.

## 업데이트

서버를 종료하고 기존 `data` 폴더 전체를 백업하세요. 새 프로젝트를 별도 폴더에 풀고 기존 `data` 폴더 전체를 복사한 뒤 `START-LOCAL.cmd`를 실행합니다. `node_modules`는 복사할 필요가 없습니다. Edge에서 **Ctrl+F5**로 새로고침하세요.

## 검증

- `npm test`: 기존 결재·권한·첨부·회계·휴가 자동 테스트.
- `scripts/document-copy-smoke.mjs`: 16개 현행 양식, 5개 결재 상태, 기존 연구개발비 양식, 새 작성자·문서번호·빈 결재 이력, 원문 불변, 독립 PDF/PNG 첨부, 취소 및 첨부 다운로드 실패 확인. 임시 DB와 합성 증빙 파일만 사용합니다.
- `scripts/document-resubmission-smoke.mjs`: 기존 문서 수정·반려·재승인·재상신 회귀 검증.
