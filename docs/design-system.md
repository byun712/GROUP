# UI 디자인 원칙

- 기존 업무 흐름과 메뉴 배치는 유지하고 `public/design.css`에서 공통 표면·색상·타이포그래피를 정의합니다.
- 밝은 회색 배경, 흰 카드, 중립 테두리와 약한 그림자를 사용합니다. 모듈별 색상은 선택된 메뉴와 주요 동작에 유지합니다.
- 글꼴은 로컬 Pretendard가 있으면 사용하고, 기본 배포에서는 포함된 Noto Sans KR을 사용합니다. 외부 폰트 요청은 필요하지 않습니다.
- 상태는 파스텔 배경과 진한 텍스트로 표현합니다. 키보드 포커스를 표시하고 reduced-motion 설정에서는 애니메이션을 끕니다.

## 프로젝트 차트

- 상단 도넛은 조회 가능한 전체 프로젝트의 공정을 완료·진행 중·대기·보류 개수 비중으로 표시합니다.
- 중앙 퍼센트는 전체 공정 진척률의 단순 평균입니다. 프로젝트별 가중치는 적용하지 않습니다.
- 공정이 없으면 0%와 빈 상태를 표시합니다. 범례와 접근성 텍스트로 색상 없이도 수치를 확인할 수 있습니다.
- 프로젝트 카드와 선택한 월의 공정 내역은 기존 진척률 값으로 네이티브 progress 막대를 표시합니다.

## 검증

`npm test`와 `scripts/menu-notice-color-smoke.mjs`로 기존 기능, 완료/대기 공정의 평균 50%, 공정별 0/100% 막대, 모바일 가로 넘침을 확인합니다.
