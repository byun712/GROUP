# 기안 메뉴 · 자동 확장 양식 · 엑셀 · 결재 서명

## 실행/업데이트

서버를 종료하고 새 폴더에 전체 ZIP을 풀어 기존 `data` 폴더 전체를 복사합니다. `START-LOCAL.cmd`는 Node.js 24 이상에서 필요한 패키지(Nodemailer, Mailparser, ExcelJS, image-size)를 확인하고 누락되면 `npm ci`로 설치합니다. 첫 설치에는 인터넷 연결이 필요합니다. PowerShell에서 직접 실행한다면 **`npm.cmd ci` 후 `npm.cmd start`** 순서로 실행하세요. 서버 시작 후 Edge에서 Ctrl+F5로 새로고침합니다.

## 좌측 기안 메뉴

홈이나 다른 업무 메뉴에서는 신규기안과 양식 목록을 감춥니다. **좌측 전자결재**를 클릭하면 신규기안 버튼과 기존 12개 양식 목록이 같은 바 아래에 펼쳐집니다. 목록은 화면 위로 뜨는 팝업 대신 세로 목록으로 표시합니다. 신규기안을 눌러 접거나 다시 펼칠 수 있고 다른 업무로 이동하면 감춥니다. 결재 대기/내 상신/운영 조회 바로가기는 기존 권한대로 유지합니다.

## 입력칸 자동 확장

전자결재와 업무보고의 긴 내용 입력칸은 줄 수에 따라 높이가 늘어납니다. 입력칸 안의 세로 스크롤을 없애고 내용이 짧아지면 기본 높이까지 줄입니다. 화면 폭·폰트 로딩·양식 전환·초기화에도 다시 높이를 계산합니다. 긴 내용으로 페이지 전체 길이가 늘어나는 경우에는 페이지 또는 문서 대화상자를 스크롤해서 확인합니다.

## 엑셀 다운로드

- 작성 화면의 **엑셀 다운로드**: 입력한 내용 그대로 내보내며 빈 필수 항목이 있어도 다운로드할 수 있습니다. 저장/상신하지는 않습니다. 전자결재 12종과 업무보고 4종 모두 지원합니다.
- 문서 상세의 **엑셀 다운로드**: 저장된 문서 내용·문서번호·작성자·상태·결재 이력·등록된 결재 이미지/날짜를 포함합니다. 기존 연구개발비 지출결의서도 저장 문서에서 내려받을 수 있습니다.
- 파일은 실제 **`.xlsx`** 형식입니다. 긴 본문은 여러 행으로 나누어 전체 내용을 담고 셀 줄바꿈·행 높이·인쇄 영역을 설정합니다. 일일업무일지의 실시/예정 좌우 배치도 유지합니다. 지출 항목 금액은 숫자로 내보내고 텍스트는 수식으로 실행하지 않습니다.
- 문서 조회 권한과 같은 권한으로 파일을 내려받을 수 있습니다. 일반 직원이 다른 사람의 문서 번호를 바꿔 요청하면 파일을 받지 못합니다.

엑셀 파일에도 Noto Sans KR을 지정합니다. 엑셀에서 같은 글꼴로 보려면 PC에 해당 글꼴이 설치되어 있어야 하며 `public/fonts/NotoSansKR-Variable.ttf`를 사용할 수 있습니다.

## 결재자 서명·도장

1. **이사 또는 대표이사 결재 역할**로 로그인합니다. Admin 권한만 있는 직원 계정에는 이 메뉴를 제공하지 않습니다.
2. 좌측 **서명·도장 등록**에서 본인의 PNG/JPG 파일을 등록합니다. 512KB 이하, 가로·세로 2000px 이하이며 투명 배경 PNG도 사용할 수 있습니다. 실제 서명/도장 파일은 본인이 준비합니다. 다른 결재자의 이미지를 대신 등록하는 기능은 제공하지 않습니다.
3. 이후 결재하는 휴가/지출/일반 기안/업무보고의 결재 칸에 **결재 날짜·시각(한국 시간), 이미지, 이름**이 표시됩니다. 반려도 실제 처리 날짜와 이미지로 구분합니다.
4. 등록 이미지를 바꾸거나 삭제해도 이미 결재한 문서의 이미지는 변하지 않습니다. 결재 시점의 이름·역할·이미지를 별도로 저장하기 때문입니다.

등록 전에 처리한 기존 결재에는 실제 처리 날짜와 `서명 미등록`을 표시하며 나중에 등록한 이미지를 소급 적용하지 않습니다. 이미지 미등록 상태에서도 기존 결재 기능은 사용할 수 있습니다.

본인 등록 이미지와 문서별 결재 이미지는 DB에 저장하고 외부 서비스로 전송하지 않습니다. 본인 이미지 등록/수정/삭제는 결재권한자 본인만 할 수 있고, 문서 이미지는 해당 문서를 조회할 권한이 있는 사용자만 볼 수 있습니다. DB 백업에 포함됩니다. 문서 삭제 시 해당 문서의 이미지 사본을 삭제하고, Admin의 사용자 영구 삭제는 그 사용자의 등록 이미지와 해당 인원의 결재 이미지도 함께 정리합니다.

## 검증

`npm test` 25개: 16종 양식 XLSX 생성·재열기, 텍스트 수식 실행 방지, 조회 권한, 이사/대표이사 전용 이미지 등록, 이미지 변경 후 기존 결재 이미지/이름 보존, 4종 문서의 이미지 삽입, 결재 날짜, 문서/사용자 삭제 시 이미지 정리, 백업/복원을 포함합니다.

`scripts/forms-signatures-smoke.mjs`: 메뉴 조건부 표시, PC/모바일 입력칸 확장, 작성 중 기안·업무보고 다운로드, 결재자 등록 메뉴, 결재 날짜/이미지 표시, 저장 문서 엑셀의 이미지 2개 포함을 검사합니다. 테스트 이미지에는 저장소의 기존 아이콘을 사용하며 실제 직원의 서명·도장을 기본값으로 넣지 않습니다.

Windows 명령 파일 자체는 Linux 환경에서 실행하지 않았습니다. 같은 Node 패키지 불러오기, `npm ci`, 서버와 브라우저 동작을 검증했습니다.
