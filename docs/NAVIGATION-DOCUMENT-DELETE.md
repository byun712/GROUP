# 바형 메뉴 · 문서 삭제 · 개인 메일함 바로 만들기

## 메뉴

좌측 메뉴는 PC/모바일 모두 **한 줄에 하나씩 가로 바**로 표시합니다. 신규기안과 하위 결재 메뉴도 같은 폭의 세로 목록을 사용합니다. 신규기안/양식 목록의 조건부 표시는 [최신 양식 안내](FORMS-EXCEL-SIGNATURES.md)를 따릅니다. 상단 업무 앱, 좌측 메뉴, 메일함 메뉴에는 얕은 그림자·윗면 하이라이트·누름 효과를 적용했습니다. 기본 보라색과 메뉴별 로고 색상은 유지합니다.

## 문서 단위 삭제

휴가신청서, 지출결의서, 전자결재 일반 기안, 업무보고 4개 양식의 상세 화면에서 **문서 삭제**를 누릅니다. 삭제 확인 체크 후 저장하면 문서와 연결된 결재 처리 이력을 실제 삭제합니다. 휴지통이나 복원 기능은 제공하지 않습니다.

| 문서 상태 | 작성자 | Admin | 다른 일반 결재자/사용자 |
|---|---|---|---|
| 이사 결재 대기 | 삭제 가능 | 삭제 가능 | 삭제 불가 |
| 이사 승인 후 대표이사 결재 대기 | 삭제 가능 | 삭제 가능 | 삭제 불가 |
| 이사 반려 또는 작성자 회수 | 삭제 가능 | 삭제 가능 | 삭제 불가 |
| 대표이사 승인 완료 | 삭제 불가 | 삭제 불가 | 삭제 불가 |
| 대표이사 반려 | 삭제 불가 | 삭제 불가 | 삭제 불가 |

Admin은 결재 역할이 직원이어도 전체 문서를 조회하고 위 범위 안에서 삭제할 수 있습니다. Admin 권한만으로 결재 승인이나 회계 접근 권한을 얻지는 않습니다. 일반 직원은 본인 문서만 조회하고, 다른 직원 문서를 삭제하는 API 요청도 거절합니다.

삭제 확인 중 결재 상태가 바뀌면 재조회를 요구합니다. 대표이사 처리 여부를 문서에 저장하므로 결재자의 권한 변경이나 계정 삭제로 이력이 정리되어도 삭제 제한을 유지합니다. 기존 자료는 승인 상태·결재 순서로 해당 표시를 채우며, 문서 번호는 삭제 후 재사용하지 않습니다. 일반 기안과 업무보고는 경로를 구분해 다른 종류의 문서로 요청하면 거절합니다. 회계 연동 기록이 남은 지출은 삭제를 막습니다.

이 규칙은 **문서 상세 화면에서의 삭제**에 적용합니다. 기존에 별도로 요청한 Admin의 사용자 영구 삭제는 해당 계정과 연결된 모든 자료를 삭제하는 기존 정책을 유지합니다. 별도 백업/내보낸 파일까지 자동으로 삭제하는 기능은 아닙니다.

## 개인 메일함

이메일 화면 왼쪽의 **＋ 메일함 만들기** 버튼에서 바로 이름을 입력해 생성합니다. 본인의 연결된 외부 메일 계정을 먼저 선택하세요. Admin 권한은 필요하지 않습니다.

메일함 이름 변경·삭제·자동 분류 규칙은 기존 **메일함·자동 분류** 설정에서 계속 관리합니다. 본인 계정에만 적용되며 다른 사용자의 계정에는 생성·수정할 수 없습니다. 외부 카페24 서버 폴더를 만드는 기능이 아니라 그룹웨어 내부 개인 메일함입니다.

## 검증

자동 테스트 24개: 4종 문서의 작성자/Admin 삭제, 타인 차단, 대표 승인/반려 후 차단, 이사 승인 후 삭제, 이력 삭제, 기존 문서 변환, 결재 상태 충돌, 번호 재사용 방지와 기존 기능을 검사합니다.

브라우저 검증 `scripts/navigation-delete-smoke.mjs`: PC/모바일 한 줄 바형 메뉴, 그림자, 휴가/지출/일반 기안/업무보고 각각의 삭제 확인·목록 갱신, 일반 직원의 개인 메일함 바로 생성을 확인합니다.
