# 메뉴·공지사항·프로젝트 색상

상단과 좌측의 주 메뉴는 프로젝트 → 전자메일 → 전자결재 → 업무보고 → 일정관리 → 공지사항 → 근태관리 → 세무회계 → 고객관리 → 사용자 순서입니다. 회계 접근 권한은 기존과 같습니다. 좌측 홈 바로 아래에는 결재 대기와 내 상신 문서를 정사각형으로 나란히 배치합니다. 결재 대기는 결재 역할이 있는 계정에 표시됩니다.

공지 작성창은 게시판·작성자·제목·내용·첨부파일 순서입니다. 작성자는 로그인한 사용자로 고정됩니다. 기존 작성 권한(이사·대표이사)은 유지하며, 등록된 공지는 작성자 또는 Admin이 수정할 수 있습니다. 수정 이력은 별도로 저장하지 않고 답변과 최초 작성 정보는 유지합니다.

첨부파일은 최대 5개, 개당 5MB, 합계 10MB입니다. 수정창에서 기존 파일을 유지·삭제하거나 새 파일을 추가할 수 있습니다. 공지를 열람하는 모든 로그인 사용자가 다운로드할 수 있으며 비로그인 다운로드는 차단합니다. 파일은 실행·미리보기하지 않고 다운로드로 제공합니다. 첨부 내용은 SQLite에 저장되므로 기존 DB 백업에 함께 포함됩니다.

프로젝트 등록·수정에서 그룹웨어의 보라·파랑·초록·주황·노랑·빨강·청록 및 회색을 선택합니다. 기존 프로젝트는 최초 스키마 갱신 시 색상을 순차 배정하며 이후 선택한 색상을 유지합니다. 카드의 색상 표시와 프로젝트 공정, 연결 일정에 반영됩니다. 홈·일정관리·프로젝트 달력에서 연결 일정의 배경색은 프로젝트 색상을 따르고, 글자는 배경 밝기에 따라 흰색 또는 어두운색으로 표시됩니다.

업데이트 전 기존 DB를 백업하고 서버를 재시작한 뒤 브라우저를 새로고침하세요. 스키마는 기존 데이터를 유지하며 필요한 테이블과 열을 추가합니다.

검증: `npm test`. 브라우저 검증: `node scripts/menu-notice-color-smoke.mjs` (별도 Playwright/Chromium 필요, `PLAYWRIGHT_MODULE`과 `BROWSER_EXECUTABLE` 지원). 자동 검증은 임시 DB를 사용합니다.
