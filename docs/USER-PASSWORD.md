# 홈 결재 카드와 비밀번호 변경

홈의 결재 진행·승인 대기 카드는 PC에서 폭을 **84px → 210px(2.5배)**로 넓혔습니다. 높이 84px와 기존 보라색·파란색을 유지하며 배너의 왼쪽 끝에 나란히 표시합니다. 배너 안내 문구는 카드 오른쪽에 표시합니다. 모바일에서는 두 카드가 화면 폭에 맞춰 줄어듭니다.

## 비밀번호 변경 위치

**사용자 관리 → 사용자 카드 → 비밀번호 변경**을 누릅니다. 이전의 계정 설정 메뉴와 비밀번호 초기화 버튼을 이 경로로 통합했습니다. 전체 메뉴의 **사용자 정보 · 비밀번호 변경**도 사용자 관리로 이동합니다.

- 본인 계정: 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 입력합니다. Admin 본인도 같은 절차입니다.
- Admin이 다른 사용자 계정 변경: 해당 사용자의 새 비밀번호와 확인을 입력합니다. 기존 비밀번호는 입력하지 않습니다.
- 일반 사용자는 본인의 비밀번호만 변경할 수 있습니다.
- 새 비밀번호는 기존 정책과 같이 12~256자입니다. 변경된 계정의 모든 기기 세션이 종료되며 새 비밀번호로 다시 로그인합니다. Admin이 다른 계정을 변경하면 Admin 본인의 로그인은 유지됩니다.

비밀번호 창은 사용자 정보 창 위에 별도로 열립니다. 취소하거나 다른 사용자의 비밀번호 변경을 마친 뒤에도 수정 중이던 프로필 입력값이 유지됩니다. 비밀번호 입력값은 창을 닫을 때 비웁니다.

## 적용과 검증

서버 종료 → 기존 `data` 전체 백업 → 새 프로젝트 폴더에 `data` 복사 → `START-LOCAL.cmd` 실행 → Edge **Ctrl+F5**.

자동 테스트와 `scripts/user-password-smoke.mjs`, 기존 프로필·홈 게시판 브라우저 검증을 사용합니다. 임시 계정으로 현재 비밀번호 오류, 확인 불일치, 본인/Admin 구분, 세션 종료, 이전·새 비밀번호 로그인, 프로필 입력 보존과 모바일 화면을 확인합니다.
