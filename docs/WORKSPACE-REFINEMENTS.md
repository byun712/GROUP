# 홈 크기·메뉴 위치·고객사 메일·근태 CSV·휴가 팝업

## 화면 구성

- 홈의 **오늘의 출퇴근·최근 공지사항** 박스는 높이와 안쪽 여백을 약 2/3로 줄였습니다. 공지 내용이 많으면 박스 안에서 스크롤합니다.
- 홈 캘린더의 날짜 칸은 84px → 100.8px, 일정관리 날짜 칸은 100px → 120px로 높였습니다. 작은 화면에서도 이전 높이의 20%를 늘렸습니다. 요일 제목과 좌측 작은 달력은 제외합니다.
- 전자결재·업무보고 양식 버튼은 PC에서 **한 줄 6개**입니다. 좁은 창에서는 3개, 모바일에서는 2개씩 표시합니다.
- **결재 운영 조회**, **서명·도장 등록**을 사용자 관리 하위로 옮겼습니다. 현재 저장소의 기존 하위 메뉴인 **휴가 관리**와 같은 단계입니다. 별도 메뉴 관리 기능을 신설하지는 않았습니다.
- 사용자 관리를 누르면 허용된 하위 메뉴가 보입니다. 결재 운영 조회·휴가 관리는 Admin, 서명·도장 등록은 이사·대표이사 결재권한자가 이용합니다. Admin 여부와 결재 역할의 기존 구분을 유지합니다.

## 고객사 이메일로 메일 작성

고객사 목록 또는 담당자 상세에서 이메일 주소를 누르면 그룹웨어 메일 작성 창이 열리고 **받는 사람**이 자동 입력됩니다. 본인에게 연결된 발신 계정을 선택하고 제목·내용·첨부파일을 작성한 뒤 **메일 보내기**를 누르세요. 이메일 주소를 누르는 것만으로 발송하지 않습니다.

저장된 텍스트 서명은 선택한 발신 계정에 맞춰 미리 표시하고, 실제 발송 시 한 번만 추가합니다. 발신 계정이 없으면 수신자와 작성 내용을 유지한 상태에서 **메일 계정 연결**을 진행할 수 있습니다. 기존 POP3·SMTP·첨부파일 기능을 사용하며 외부 이메일 프로그램을 실행하지 않습니다.

## 근태 CSV

근태 관리에서 사용자·조회 월을 선택한 뒤 **CSV 다운로드**를 누릅니다. 일반 직원은 본인, Admin은 선택한 사용자의 기록을 내려받습니다.

- 상단: 이름·직급·소속조직 / 아이디·이메일·전화번호 / 조회 월.
- 하단 3열: 날짜 / 출근 시각 (한국 시간) / 퇴근 시각 (한국 시간).
- 시각은 화면처럼 `2026. 11. 2. 오전 8:54:28` 형식이며 초까지 포함합니다. 퇴근 미등록은 `—`로 표시합니다.
- UTF-8 BOM과 CSV 인용 처리를 적용해 한글·쉼표·줄바꿈을 보존합니다. 수식으로 오인될 수 있는 직원 정보는 텍스트로 처리합니다.

**CSV에는 색상·테두리·병합 셀을 저장할 수 없습니다.** 이미지의 항목과 표 구성을 반영하며, 출근 파랑·퇴근 빨강 표시는 웹 근태 화면에서 유지합니다.

## 휴가 잔여일 팝업

휴가 신청서 위쪽의 **휴가 잔여일 확인**을 누르세요. 신청 시작일의 연도가 기본 선택되며, 날짜를 아직 정하지 않았으면 한국 시간 기준 현재 연도를 사용합니다. 팝업에서 연도를 바꿔 다시 조회할 수 있습니다.

본인의 이름·직급·소속, 입사일·퇴사일·근속연차·공제일·이월연차와 연차·정기휴가·보건휴가·포상휴가별 **사용/지급, 잔여, 결재 대기, 신청 가능** 일수를 표시합니다. 결재 대기분은 잔여에서 예약되므로 실제 신청 가능한 일수를 따로 보여줍니다.

근속연차는 입사일을 기준으로 현재 연도는 오늘, 다른 연도는 연말까지 계산하며 퇴사일이 더 빠르면 그 날짜까지만 계산합니다. 입사일이 없으면 `—`로 표시합니다. 휴가 부여 일수는 Admin이 저장한 값을 사용합니다. 팝업은 조회 전용이며 기존 휴가 소진 차단과 평일 차감 규칙을 유지합니다.

## 적용과 검증

서버 종료 → 기존 `data` 전체 백업 → 새 프로젝트 폴더에 기존 `data` 전체 복사 → `START-LOCAL.cmd` 실행 → Edge **Ctrl+F5**. `node_modules`는 복사하지 않아도 됩니다.

검증은 `npm test`, `scripts/workspace-refinements-smoke.mjs`, 기존 메일·서명 등록 브라우저 검증을 사용합니다. 임시 데이터만 사용하며 고객사 이메일 발송 검증은 요청을 로컬에서 가로채므로 외부 메일을 보내지 않습니다.
