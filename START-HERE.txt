모아 ToDo — 실행 안내

1. Node.js 24 이상을 설치합니다: https://nodejs.org/
2. ZIP 전체를 압축 해제합니다. ZIP 안에서 직접 실행하지 마세요.
3. Windows: 압축 해제한 폴더의 START-TODO.cmd를 실행합니다.
   macOS / Linux: 그 폴더에서 터미널을 열고 sh START-TODO.sh를 실행합니다.
4. 브라우저에서 http://127.0.0.1:4174/todo/ 를 엽니다.
5. 서버 터미널은 열어 둡니다. 종료할 때는 Ctrl+C를 누릅니다.

직접 실행: node scripts/serve.mjs --preview
빌드 파일이 포함되어 있으므로 처음 실행할 때 npm 설치나 빌드가 필요하지 않습니다.
index.html을 더블클릭하는 방식은 지원하지 않습니다.

데이터는 이 브라우저에 저장됩니다. GROUP 미연결이며 다른 기기에 동기화되지 않습니다.
계속 같은 주소·포트·브라우저 프로필을 사용하세요.
설정 및 데이터 → JSON 내보내기로 데이터를 별도 백업하세요.

전체 기능, 실행 문제 해결, 개발·빌드 방법은 README.md를 참고하세요.
