# 지출결의서 비용 항목·거래처·첨부 증빙

전자결재 → 신규기안 → 지출결의서에서 사용합니다.

## 비용과 거래처

- 비용 구분에 **4대보험, 공과금, 급여**를 추가했습니다.
- 각 지출 항목에 **항목 거래처명**과 **거래처 추가 정보(계좌·연락처 등)**를 입력할 수 있습니다.
- 모든 항목이 같은 거래처라면 위쪽 **공통 거래처**만 입력해도 됩니다. 항목 거래처를 따로 입력하면 그 값을 우선 적용합니다. 공통 거래처를 생략하는 경우 모든 항목에 거래처명을 입력하세요.
- 증빙 종류에 **납부고지서, 납부확인서, 급여명세서**를 추가했습니다.
- 기존 공급가액·부가세 입력과 합계 계산을 유지합니다. 실제 금액에 맞게 입력하세요.
- 최종 대표이사 승인 시 회계 계정 **506: 4대보험 / 507: 공과금 / 508: 급여**에 연동합니다. 기존 결재·지급 흐름과 중복 방지 규칙을 유지합니다.

## 첨부파일과 미리보기

1. 작성 화면의 **증빙 첨부파일 → 파일 추가**에서 파일을 선택합니다.
2. 목록에서 파일명을 누르면 저장 전에도 미리볼 수 있습니다. PDF는 이전·다음, 페이지 번호, 확대 기능을 제공합니다. PNG/JPG는 이미지로 표시합니다.
3. **지출결의서 상신** 또는 **수정 저장** 시 문서 내용과 첨부파일을 함께 저장합니다. 저장 전에 창을 닫거나 새 양식으로 이동하면 선택한 새 파일은 서버에 남지 않습니다.
4. 저장한 문서 상세에서 **증빙 첨부파일 → 미리보기 / 다운로드**로 확인합니다.
5. 파일을 바꾸려면 **문서 수정**에서 제거·추가한 뒤 **수정 저장**합니다. 제거 버튼만 누르고 취소하면 기존 파일은 유지됩니다.

지원 형식은 **PDF·PNG·JPG/JPEG**, 개당 **10MB**, 최대 **10개**, 합계 **20MB**입니다. 파일 확장자와 실제 형식을 확인합니다. 암호화 PDF는 원본을 다운로드한 뒤 암호를 입력해 확인하세요. 다른 문서 형식은 PDF로 저장한 뒤 첨부합니다.

조회 권한은 원문과 같습니다. 작성자, Admin, 이사·대표이사 결재권한자가 볼 수 있고 일반 직원은 다른 직원의 문서 첨부파일에 접근할 수 없습니다. 첨부 변경은 작성자의 문서 수정 가능 단계(이사 승인 전, 반려, 회수)에서만 가능합니다. 최종 승인된 증빙은 변경할 수 없습니다.

## 엑셀·보관

문서 화면과 엑셀에는 항목별 거래처·추가 정보가 반영됩니다. 엑셀에는 **첨부파일 목록**을 출력하며, PDF나 이미지를 엑셀 안에 삽입하지 않습니다. 증빙 원본은 미리보기의 **원본 다운로드**로 받으세요. 기존 A4/PDF 인쇄 설정은 유지합니다.

첨부 원본은 `data/group.db` 안에 저장되어 DB 백업·복원에 포함됩니다. 허용된 문서 삭제 또는 Admin의 사용자 영구 삭제 시 관련 첨부 원본도 함께 삭제됩니다. 업로드·수정이 실패한 경우 문서나 일부 첨부만 따로 저장되지 않습니다.

## 업데이트

서버를 종료하고 기존 `data` 전체를 백업합니다. 새 프로젝트 폴더에 기존 **`data` 폴더 전체**를 복사한 뒤 `START-LOCAL.cmd`를 실행하세요. 첫 실행에 PDF 미리보기 패키지를 자동 설치하므로 인터넷 연결이 필요합니다. `node_modules`는 복사할 필요가 없습니다. PowerShell에서 직접 실행한다면 프로젝트 폴더에서 `npm.cmd ci` 후 `npm.cmd start`를 실행합니다. Edge에서 `Ctrl+F5`로 새로고침합니다.

PDF 미리보기는 Mozilla **PDF.js 6.5.438 (Apache-2.0)**을 서버에서 제공합니다. 외부 문서 변환 서비스로 파일을 전송하지 않습니다. 첨부한 PDF의 스크립트나 링크를 실행하지 않고 페이지를 캔버스로 표시합니다.

검증: `npm test`, `scripts/expense-attachments-smoke.mjs`. 자동 테스트는 합성 PDF와 임시 DB를 사용합니다. 브라우저 스크립트의 `EXPENSE_SAMPLE_PDF`에 로컬 PDF 경로를 지정해 별도 파일도 검증할 수 있습니다. 회사 증빙 파일은 저장소·배포 ZIP에 포함하지 않습니다.
