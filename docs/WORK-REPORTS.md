# 업무보고 · 로고 색상 테마

## 업무보고 메뉴

좌측 메뉴 또는 상단 박스형 업무 앱의 **업무보고**를 엽니다. 4개의 양식 카드 또는 **업무보고 작성 ▾**에서 양식을 선택합니다. 주간회의록/주간보고 등 요청하지 않은 양식은 추가하지 않았습니다.

| 양식 | 구성 |
|---|---|
| 교육계획서 | 교육명, 기간, 장소, 교육기관·강사, 대상·참석 예정자, 목적, 교육 내용·세부 일정, 예상 교육비, 기대 효과 |
| 교육보고서 | 교육명, 기간, 장소, 교육기관·강사, 참석자, 교육 내용, 교육 결과·소감, 업무 적용 계획, 실제 교육비 |
| 회의록 | 회의일, 시작·종료 시각, 장소, 참석자, 안건, 논의 내용, 결정사항, 후속조치·담당자·완료 예정일 |
| 일일업무일지 | 제목·일자, 실시사항과 예정사항의 좌우 배치, 아래 전체 폭의 진행업무, 특이사항 |

일일업무일지는 사용자가 제공한 이미지의 항목과 배치를 반영했습니다. 기대 효과, 회의 후속조치, 일일업무일지의 진행업무/특이사항은 선택 항목입니다. 교육비는 0원 이상 정수로 입력하고 기간의 시작/종료일과 회의 시각을 검증합니다. 회의록은 같은 날짜의 회의를 기록하며 자정을 넘는 회의는 날짜별로 나눕니다. 문서 작성자는 로그인한 사용자 정보로 표시합니다.

### 웹 양식 조사 제한

2026-10-27에 Google/Bing/Naver 검색과 예스폼(www.yesform.com), 비즈폼(www.bizforms.co.kr)에 접근을 시도했으나 실행 환경의 네트워크 프록시에서 **403 Forbidden**으로 차단했습니다. 실제 웹 양식을 열어 비교했다거나 가장 많이 쓰이는 양식으로 검증했다고 주장하지 않습니다. 위 3개 일반 보고 양식은 통상적인 기업 서식의 공통 항목을 기준으로 자체 구성했으며 특정 업체의 유료 양식을 복제하지 않았습니다. 일일업무일지는 제공된 이미지를 기준으로 했습니다.

## 결재 시스템

- 직원: 본인이 작성한 보고서만 조회하고 상신합니다.
- 이사/대표이사 결재 역할: 보고서를 검토하고 현재 본인의 단계에서 승인/반려합니다. Admin 권한만으로 결재 권한을 얻지는 않습니다.
- 결재 순서: **작성자 → 이사 → 대표이사**. 이사 승인 전까지만 작성자가 회수할 수 있습니다.
- 이사와 대표이사 모두 본인 문서의 해당 결재 단계에서 승인할 수 있습니다. 대표이사의 문서도 먼저 이사 승인을 거칩니다.
- 업무보고함: 전체·결재 대기·진행·승인 완료·반려·회수·내 상신, 양식별/검색 필터, 10개씩 페이지.
- 문서번호: WR-00001 형식. 상세 화면에서 결재 단계와 처리 이력을 표시합니다.
- 기존 **결재 대기** 메뉴와 홈 업무 현황에도 업무보고가 함께 표시됩니다. 기존 전자결재의 신규기안 12개 양식은 유지하고 업무보고 4개를 별도 메뉴에서 제공합니다.

보고서는 기존 결재 DB/이력 테이블에 저장하고 기존 자료를 삭제하지 않습니다. DB 백업/복원에 포함되며 사용자 영구 삭제 시 해당 사용자의 업무보고와 결재 기록도 함께 삭제됩니다. 일반 기안과 업무보고는 API 조회/상신 경로를 나누고 다른 종류의 경로로 문서 결재를 요청하면 거절합니다. 사내 이사/대표라는 직급 표기와 서버의 결재 역할은 별개입니다.

## 메뉴별 색상

흰 바탕과 Noto Sans KR 글꼴을 유지하고 엘솔텍 로고의 보라색을 전체 기본색으로 사용합니다. 메뉴를 바꾸면 제목·주요 버튼·선택 탭·표 머리글·문서 대화상자의 강조색이 바뀝니다. 업무 앱의 아이콘도 각 메뉴 색상으로 구분합니다.

| 메뉴 | 강조색 |
|---|---|
| 홈·업무보고·계정 설정 | 보라 |
| 전자결재·이메일 | 파랑 |
| 프로젝트·사용자 관리 | 녹색 |
| 고객사 | 주황 |
| 근태 | 노랑/금색 |
| 회계·공지사항 | 붉은색 |
| 일정관리 | 하늘색/청록 |

승인 완료/반려 등 상태 표시는 구분을 위해 녹색/붉은색 의미를 유지합니다. 노란색 계열의 버튼과 글자는 흰 배경에서 읽을 수 있는 진한 금색을 사용합니다.

## 검증

`npm test` 23개: 보고 양식/선택 항목/입력 검증, 본인/타 직원 격리, 4종 상신과 단계별 승인·반려·회수·본인 승인, 결재 대기함 통합, 20,000자 일지 저장, 백업/복원을 포함합니다.

선택 브라우저 검증: `scripts/reports-smoke.mjs`. 네 양식 작성, 이미지와 유사한 일일업무일지 배치, 모바일 폭, 텍스트 안전 표시, 업무보고함→통합 대기함의 순차 결재, 새로고침 후 보존, 메뉴별 실제 강조색을 검사합니다.
